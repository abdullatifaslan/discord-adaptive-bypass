# Contributing Guidelines

Thank you for considering contributing to Adaptive Discord Bypass Engine! 

## Branch Strategy
* **`master`**: Maintained for stable, production-ready code only.
* **`develop`**: Main development branch. All feature branches and PRs must target `develop`.

## How to Contribute
1. Fork the repository.
2. Create a feature branch off from the `develop` branch:
   `git checkout develop`
   `git pull origin develop`
   `git checkout -b feature/YourFeatureName`
3. Commit your changes with a clear message:
   `git commit -m "Add some feature"`
4. Push to your branch:
   `git push origin feat/YourFeatureName`
5. Open a **Pull Request against the `develop` branch** (do not target `master` directly).

## Reporting Issues & Questions
* Check if the issue is already reported before creating a new one.
* Provide details about your OS, ISP (Internet Service Provider), and steps to reproduce.
* If you have general questions or ideas, feel free to open a discussion in the repository.
