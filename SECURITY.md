## Reporting a Vulnerability

We take the security of Adaptive Discord Bypass Engine seriously. If you discover a security vulnerability, please follow these steps:

1. **Do not create a public issue** for security vulnerabilities.
2. Report the vulnerability directly via GitHub Security Advisories or by contacting the maintainer via GitHub profile.
3. Provide details about the vulnerability, including steps to reproduce and potential impact.

We will review your report and respond as quickly as possible to address any valid concerns.
